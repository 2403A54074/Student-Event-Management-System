\# Student Event Management System



\## Project Overview

CampusConnect is a simple web application that helps students explore upcoming college events.



\## Features

\- View college events

\- Display event dates and times

\- Read event descriptions

\- Responsive webpage design

\- Git and GitHub version control

\- Feature branching and merging

\- GitHub Pages deployment



\## Technologies Used

\- HTML5

\- CSS3

\- JavaScript

\- Git

\- GitHub
